## Настройка MounRiver Studio

Для сборки и прошивки проекта вам понадобится [MounRiver Studio](http://mounriver.com) (MRS).

### Шаги для быстрого старта:
1. **Скачайте IDE**: Загрузите и установите последнюю версию с [официального сайта](http://mounriver.com).
2. **Импортируйте проект**: 
   * Откройте MounRiver Studio.
   * Выберите `File` -> `Import...` -> `General` -> `Existing Projects into Workspace`.
   * Нажмите `Next`, в поле `Select root directory` укажите путь к этой папке с проектом и нажмите `Finish`.
3. **Сборка (Build)**: Нажмите на иконку **Молотка** на панели инструментов (или клавиши `Ctrl + B`), чтобы скомпилировать проект.
4. **Прошивка (Flash)**: Подключите плату через программатор (например, WCH-Link) и нажмите на иконку **Download** для загрузки прошивки.
